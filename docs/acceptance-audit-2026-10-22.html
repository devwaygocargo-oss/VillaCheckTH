ผลตรวจรับ VillaCheck — 22 ตุลาคม 2569

เทียบบรีฟเอกสารเดิมกับคำสั่งล่าสุดในแชต โดยใช้คำสั่งล่าสุดแทนข้อเดิมที่เปลี่ยนแล้ว เช่น Basic ฟรีตลอดไป หนึ่ง Villa ใหม่ต่อบัญชี และส่งสื่อทาง Facebook

ตรวจ 70 เส้นทาง × 3 ขนาดจอ = 210 กรณี, CMS 36 กรณี, Backend/PostgreSQL 202 tests ผ่านทั้งหมด ไม่มีข้าม

แก้ปัญหา Generate QR บน PostgreSQL และเลขอ้างอิงติดตามรายงานล้นจอมือถือแล้ว Facebook Login ยังรอ Meta อนุมัติ

หน้าจอตรวจด้วย Chromium ที่ 360/768/1440 px ใช้ Frontend Production กับ API แยกข้อมูลทดสอบ งานแก้ไขไม่แตะข้อมูลลูกค้า การทดสอบข้อมูลสาธารณะบน Production เป็นแบบอ่านอย่างเดียว การกล้องปฏิเสธใช้การจำลอง ไม่ใช่ผลตรวจอุปกรณ์จริงทุกชนิด
